### Description du projet

Dans ce projet, vous allez créer un scraper web en Python qui récupère les offres d'emploi du [**site **](https://realpython.github.io/fake-jobs/)[***Fake Python Jobs***](https://realpython.github.io/fake-jobs/) . Ce scraper extraira des informations telles que l'intitulé du poste, le nom de l'entreprise, le lieu et un lien vers la description complète du poste.

Ce site, conçu spécifiquement pour l'apprentissage, est idéal pour les débutants. Vous pouvez vous concentrer sur la compréhension de la structure HTML, la sélection des éléments et le traitement des données sans vous soucier des protections anti-extraction complexes ni des restrictions légales.

---

### Exigences du projet

- Récupérer les données depuis [**https://realpython.github.io/fake-jobs/**](https://realpython.github.io/fake-jobs/)
- Extrayez les champs suivants pour chaque offre d'emploi :
  - Titre d'emploi
  - Nom de l'entreprise
  - Emplacement
  - URL de la page de détails de l'emploi
- Enregistrez les résultats dans un fichier CSV
- Utilisez un code Python propre et lisible
- Gérer les cas limites simples (par exemple, les champs manquants)

---

### Technologies à utiliser

- **Python**
- **Requêtes** – pour récupérer la page web
- **Beautiful Soup (bs4)** – pour analyser et naviguer dans le HTML
- **Module CSV** – pour enregistrer les offres d'emploi

---

### Ce que vous apprendrez

Après avoir réalisé ce projet, vous saurez inspecter le code HTML d'une page web, identifier des modèles réutilisables et extraire des données structurées à l'aide de Python. Vous vous familiariserez avec l'utilisation de bibliothèques tierces, l'organisation des données extraites et leur exportation pour une analyse ultérieure. Ce projet vous préparera également à aborder des tâches d'extraction de données plus avancées, telles que la pagination, le filtrage et l'analyse de sites web réels.
